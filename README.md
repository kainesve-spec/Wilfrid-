# Wilfrid

**Wilfrid est un assistant personnel en cours de développement**, conçu pour fonctionner dans un environnement Android avec Termux.

## Principes

- Comprendre les demandes dans leur contexte.
- Distinguer les capacités disponibles des capacités simplement déclarées.
- Respecter les autorisations avant toute action.
- Vérifier les effets des actions et rapporter honnêtement les résultats.
- Préserver la traçabilité des opérations et les contrôles de sécurité.

## Projet Android

Le dépôt contient notamment :
- le code du projet Android ;
- la configuration Gradle ;
- le workflow GitHub Actions prévu pour la compilation Android ;
- le runtime Python et les modules du projet.

La compilation, l'installation et le fonctionnement complet sur appareil doivent être validés séparément. La présence du code ne signifie pas que toutes les fonctionnalités sont opérationnelles.

## Sécurité

Ne jamais publier de clés API, mots de passe, jetons d'accès ou fichiers contenant des secrets.

Toute capacité sensible doit respecter les mécanismes d'autorisation prévus par le projet.

## État du projet

Wilfrid est en développement. Les fonctionnalités doivent être considérées comme validées uniquement lorsque des tests ou des vérifications d'exécution apportent des preuves suffisantes.
